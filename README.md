# OVERVIEW
This is the supplementary data repository for the article "Introducing Covering Problems for the Electronic Wafer Test." 
It presents the problem instances belonging to the benchmark suite, a solution algorithm and the outputs for the different problem instances. 

## Organization
This repository is organized as follows:
-*CSP_Solver*: This folder contains the solution algorithm 

-*DATA*: This folder contains the output logs for the different problem instances 

-*Data_Template*: This folder contains the different wafer maps for the introduced problem instances 

-*GlobalConstants*: This file contains relevant constants for the calculation 

-*inputMapsLibrary*: This file contains references to the wafer maps in *Data_Template* for the calculations 

-*probecardLibrary*: This file contains the different probe card shapes for the calculations
