# OVERVIEW
This is the supplementary repository containing wafer maps for the article "Introducing Covering Problems for the Electronic Wafer Test." 
Wafer maps are organized by size and category. 

## Data structure
Each file is txt file containing a space-separated matrix. Left to right is the increasing x direction, up to down the increasing y direction.
The entry values classify the position. Any position classified 0 is forbidden, each position classified 1 is required, and 2 is optional.
